# Sagasu: Brand

## Logo
- `sagasu-logo-mark.svg`: symbol for light backgrounds
- `sagasu-logo-mark-white.svg`: symbol for dark (Blue Slate) backgrounds
- `sagasu-app-icon.svg`: app icon / favicon (symbol on a Blue Slate square)
- Wordmark: "Sagasu", bold, Blue Slate `#326273` (white on dark backgrounds)

Concept: magnifying glass (search) + S-shaped path (from the need to the supplier) + Tangerine dot (the supplier found).

## Palette

| Name | Hex | Use |
|---|---|---|
| Blue Slate | `#326273` | Logo, navbar, headings, primary buttons |
| Pacific Blue | `#5C9EAD` | Icons, links, active states, charts |
| Tangerine | `#E39774` | Accent: AI suggestions, selected supplier, notifications |
| White | `#FFFFFF` | Page background |
| Platinum | `#EEEEEE` | Cards, secondary backgrounds |
| Ink | `#1E2F36` | Body text |
| Light Pacific | `#A3CDD6` | Pacific Blue on dark backgrounds only |

## Contrast rules (WCAG)
- White text on Blue Slate: 6.7:1, OK for buttons.
- White text on Pacific Blue: 3.0:1, not OK for text. Use Pacific Blue for icons and borders only.
- White text on Tangerine: 2.3:1, not OK. Use Tangerine as a background accent with dark (Ink) text.

## Mascot
The AI robot is for the assistant and empty/loading states ("Sagasu is searching…"), recolored in Blue Slate and Tangerine. It is not part of the logo.
