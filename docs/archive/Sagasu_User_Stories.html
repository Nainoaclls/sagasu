Sagasu — User Stories

AI-assisted supplier discovery & bidder-list creation · Le Wagon Tokyo final project
Version 1.0 · 23 November 2026

Users

Visitor
Discovers Sagasu before signing up.
Buyer
Creates RFQ projects, reviews AI suggestions, builds the bidder list.
Approver
Manager who validates or returns bidder lists.

MVP — Demo Day scope

PriorityUser StorySo that
1As a visitor I can visit the home pageI can discover what Sagasu does
2As a user I can sign up / log inmy projects and comments are linked to me
3As a buyer I can create a Request For Quotation (RFQ) projectI can organize a new purchase
4As a buyer I can add my list of materials to a projectI can tell what I need to buy
5As a buyer I can review the AI proposal for item groups AIsimilar materials are grouped together
6As a buyer I can edit the item groups (rename, move items) AII can fix groups the AI got wrong
7As a buyer I can review the AI supplier suggestions for each group, with the reason AII understand why each supplier is recommended
8As a buyer I can select or remove suggested suppliers AII keep the final decision
9As a buyer I can search suppliers and add one to a group AII can include suppliers the AI missed
10As a buyer I can see a supplier's profile and colleagues' reviewsI benefit from my team's experience
11As a buyer I can write a review on a supplier and choose its visibilityI share knowledge without exposing sensitive info
12As a buyer I can send my bidder list for approvalmy manager can validate it
13As an approver I can see the bidder lists waiting for my approvalI know what I need to review
14As an approver I can approve or return a bidder list with a commentthe decision is validated and traceable
AI Highlighted rows are the core AI experience: grouping and supplier recommendation, always under the buyer's control.
